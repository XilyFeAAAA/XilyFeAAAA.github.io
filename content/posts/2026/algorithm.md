1. 最长连续序列：最关键是 `num-1`  找到开头的 num，其次重复数字没有用所以遍历 set 而不是 list
2. 三数之和：固定一侧降维，然后注意去重
3. 接雨水（二刷）：我的思路是竖着求面积，分别求每一个idx左边最高和右侧最高，它们两个取min再减去当前位置高度就是这个idx雨水的高度。然后单调栈的思路是横着求面积，右边第一个高的和左边第一个高的围成的就是横着的面积。
4. 找到字符串中所有字母异位词（二刷）：没想出来非暴力解。收获有两个：
	1. 从最暴力的解法开始，慢慢剪枝，例如：无需遍历所有的子串（也就是滑动窗口）。其次就是能不能想到高效的 `check` 函数，例如答案的方法就是记录了每个 char 的格式，一致则是异位词。
	2. 定长滑动窗口的解法：入-更新-出。
		1. 入：下标为 i 的元素进入窗口，更新相关统计量。如果窗口左端点 i−k+1<0，则尚未形成第一个窗口，重复第一步。
		2. 更新：更新答案。一般是更新最大值/最小值。
		3. 出：下标为 i−k+1 的元素离开窗口，更新相关统计量，为下一个循环做准备。
5. 和为 K 的子数组（二刷）：`arr[j] - arr[i] == k 且 i < j` 方法就是记录 `arr[i]` 遍历到 `arr[j]` 时候看看有没有 `k-arr[j]`。前缀和问题注意可以加一个 0 在开头。
6. 滑动窗口最大值（二刷）：滑动窗口+堆/单调队列两种做法，一个技巧就是，**不用手动删除离开窗口的元素**，而是需要记录时候判断堆顶/队头元素是不是在窗口内，如果不在则移出，这样效率高很多。
7. 最小覆盖子串（二刷）：一个关键点是，假如搜索到 x....y 覆盖了 t，那么如果存在更短的子串能够覆盖t，那么肯定在右侧。按照这个思路用双指针。
8. 最大子数组和（二刷）：前缀和+贪心/动态规划。最大子数组和就是最大的前缀和-最小的前缀和，但是注意先后顺序。动态规划 dp 就是**以 i 结尾**的最大子数组和。

70. 数组中的第K个最大元素（二刷）：
	1. 思路是，第K个最大元素在有序数组的n-k这个位置，所以可以想到快排，每次可以给一个元素确定最终位置。我们每次随机选择一个数当pivot，能得到他最终位置，假如位置=n-k，那么这个pivot就是第k大的元素，假如它的位置<n-k，那么就在它的右侧继续进行partition。
	2. 快排的parition分为Hoare partition和Lomuto partition。Hoare partition就是双指针那个方法，它的问题在于只能确保`[left, ret]` ≤ pivot，`[ret+1, right]` ≥ pivot，pivot 本身位置不定。所以return 的j不一定是pivot的位置。例如 \[4, 6, 5, 1, 2, 3] 选pivot=4经过 hoare partition 可能变成 \[3,2,1,5,6,4]，j=2，它满足<=j 的<=4 >=j的>=4，但是4不在j=2上。所以我们需要用lomuto partition，它可以让 pivot位于最终位置
	3. 对于特殊测试点，比如快排中有非常多相同元素，可以用三路排序，他把数组分为 \[小于pivot，等于pivot，大于pivot]

```python
def partition(self, left: int, right: int, nums: list[int]) -> int:
    pivot = nums[random.randint(left, right)]
    l = i = left
    r = right
    
    while i <= r:
        if nums[i] < pivot:
            nums[l], nums[i] = nums[i], nums[l]
            l += 1
            i += 1
        elif nums[i] > pivot:
            nums[i], nums[r] = nums[r], nums[i]
            r -= 1
        else:
            i += 1
    return l, r
```
